Problem A — Telemetry Noise Filter

During THE CRASH, corrupted telemetry noise flooded the primary system bus of the CIT territory. As an Operator, your task is to clean the incoming telemetry stream by filtering out all negative values caused by signal noise. You must preserve the exact relative order of all remaining non-negative data packets so diagnostic tools can parse them cleanly.

Input Format
The first line contains a single integer n — the total number of telemetry packets.
The second line contains n space-separated integers representing the packet values.

Output Format
On the first line, print an integer — the count of non-negative packets remaining.
On the second line, print the space-separated non-negative integers in their original relative order. If the count is 0, leave the second line empty.

Hint: you can print all array's elements using the following instruction: print(*your_array)

Sample Input 0
5
-3 10 -1 0 5

Sample Output 0
3
10 0 5

Sample Input 1
4
-500 -1 -9999 -42

Sample Output 1
0
