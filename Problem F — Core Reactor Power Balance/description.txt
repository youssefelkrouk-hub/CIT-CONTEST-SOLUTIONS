Problem F - Core Reactor Power Balance

To prevent a thermal meltdown, you must split the entire sequence of N cells into at most K contiguous sub-reactor partitions.

The total load of a sub-reactor partition is the sum of energy produced by all cells assigned to it. Your objective is to find the minimum possible value of the maximum load assigned to any single sub-reactor partition.

Input Format
The first line contains two space-separated integers N and K - the number of power cells and the maximum number of allowed sub-reactor partitions.
The second line contains N space-separated integers representing the energy load of each cell.

Constraints
Total energy sum can exceed the 32-bit range (use 64-bit integers).

Output Format
Return a single integer - the minimized maximum load among all sub-reactors.

Sample Input 0
5 3
2 4 7 3 5

Sample Output 0
8

Explanation 0
The optimal way to divide the 5 cells into 3 contiguous sub-reactor partitions is [2, 4], [7], and [3, 5]. The total energy loads for these partitions are 6, 7, and 8, respectively. The maximum load among these partitions is 8. No other valid partitioning configuration yields a maximum load smaller than 8.

Sample Input 1
4 4
1 2 3 4

Sample Output 1
4
